# Data Cleaning Projects
Using Python and Pandas to perform data cleaning on real world data sets, covering skills such as:
* Handling missing and duplicate data
* Correcting data types and formats
* Standardizing and transforming columns
* Preparing datasets for analysis

Source: Kaggle

[Airbnb Open Data](https://www.kaggle.com/datasets/arianazmoudeh/airbnbopendata)

[Netflix Movies and TV Shows](https://www.kaggle.com/datasets/shivamb/netflix-shows?resource=download)

[Amazon Sales Dataset](https://www.kaggle.com/datasets/karkavelrajaj/amazon-sales-dataset)
